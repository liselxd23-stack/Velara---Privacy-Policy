3. Device Permissions and On-Device Processing

To provide core lock screen functionality, Vélara requests certain system permissions. All operations occur strictly locally on your device in volatile memory (RAM):

  • Notification Listener Service BIND_NOTIFICATION_LISTENER_SERVICE — Required solely to display notification app icons, titles, and message previews on the lock screen. Notification data is processed purely in temporary memory and is never logged, persisted, or exported.
  • Camera & Flashlight CAMERA & android.hardware.camera.flash — Used exclusively to toggle the lock screen flashlight shortcut and quickly open your device camera application via secure shortcut intents. The app does not record video, capture still images, or access your photo gallery.
  • Foreground Service FOREGROUND_SERVICE & SPECIAL_USE — Maintains uninterrupted lock screen responsiveness and prevents the operating system from terminating the lock screen overlay unexpectedly.
  • Battery & Power Status Intent.ACTION_BATTERY_CHANGED — Reads local battery metrics (level, charging speed, voltage, charging technology) solely to display real-time lock screen animations (e.g. Rapid Charging, Fast Charging, and Super Fast Charging modes).
  • System Alert Window & Full-Screen Intent SYSTEM_ALERT_WINDOW / USE_FULL_SCREEN_INTENT — Allows the custom lock screen interface to be rendered over the system display when the device screen turns on or is woken.
  • Boot Completed RECEIVE_BOOT_COMPLETED — Allows the lock screen service to restore your configured custom lock screen automatically after device restart.
  • Vibration & Haptics VIBRATE — Provides tactile feedback for unlock gestures, PIN entry, and interactive lock screen controls.
  • Set Wallpaper SET_WALLPAPER — Allows applying user-chosen wallpaper backgrounds directly within the lock screen styles menu.

4. Local Data Storage and Retention

All user preferences—such as your chosen clock design, lock screen theme, animation speeds, language options, and layout configurations—are stored exclusively within your device's isolated local application sandbox (via Android SharedPreferences / Encrypted DataStore).

We do not operate external databases, cloud synchronization servers, or remote backups. You retain complete control over this data: you may erase all stored settings at any time by clearing the application's storage in Android Settings or by uninstalling the application.
